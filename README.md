# Casa do Corte — Landing Page

Landing page fictícia da barbearia **Casa do Corte**, localizada (supostamente) na Vila Madalena desde 1987.

> **Nota:** este é um projeto **fictício**, desenvolvido exclusivamente para fins de **portfólio**. A barbearia, o endereço, os telefones, os nomes (Tomás, Inês) e qualquer outra informação presente no site não são reais.

## Visão geral

Página única com seções de manifesto, livro de cortes, barbeiros, fotos da casa, agendamento via WhatsApp e rodapé com informações de contato. Tipografia serifada/sem-serifa com paleta off-white, preto carvão e vermelho-tijolo, e animações sutis de entrada (reveal por scroll, hero em cascata).

## Stack

- **HTML5** semântico
- **Tailwind CSS** (via CDN)
- **CSS customizado** em `styles.css` (variáveis, animações, nav adaptável)
- **JavaScript vanilla** em `scripts.js` (menu mobile, scroll do header, IntersectionObserver para reveal)

## Estrutura

```
.
├── index.html         # marcação da página
├── styles.css         # estilos customizados
├── scripts.js         # interações (nav, menu mobile, reveal)
└── public/
    └── images/        # imagens otimizadas em .webp
```

## Créditos

Projeto fictício de portfólio. Imagens, textos e dados são meramente ilustrativos.
